## Einleitung

### Markdown

_Markdown_ ist eine Auszeichnungssprache (_Markup Language_). Mit Auszeichnungssprache wird Text strukturiert.
Einige Markup-Languages sind z.B.:

- HTML (*Hypertext Markup Language*)
- XML (*Extensible Markup Language*)
- MD (*Markdown*)
- YAML (*YAML Ain't Markup Language* bzw. *Yet Another Markup Language*)

Markdown ist heutzutage eine der beliebtesten Auszeichnungssprachen. Es wird vor allem in der Softwareentwicklung und in der Dokumentation verwendet. Markdown-Dateien haben die Dateiendung `.md`.

Um ein Git-Repository zu erstellen, muss man zunächst ein Verzeichnis anlegen. In diesem Verzeichnis kann man dann eine README.md-Datei erstellen. Diese Datei ist die Hauptdokumentation des Projekts und wird auf GitHub automatisch angezeigt.

- im gewünschten Verzeichnis ein Terminal (bzw. CLI-_Command Line Interface_) den Befehl `git init` ausführen, um ein Git-Repository zu erstellen.

**Einschub zur Installation von Git:**

Falls bei der Eingabe von `git init` die Meldung `git: command not found` erscheint, muss Git zunächst installiert werden. Die Installation von Git ist auf den meisten Betriebssystemen sehr einfach. Auf Windows kann man Git z.B. über den Installer von [git-scm.com](https://git-scm.com/) installieren. Auf Linux kann man Git über den Paketmanager installieren, z.B. mit dem Befehl `sudo apt install git` auf Debian-basierten Systemen.

-dann in GitHub-Desktop ein neues Repository erstellen und das lokale Repository mit dem GitHub-Repository verbinden.

-nun kann die schaltfläche **Commit to master** betätigt werden, um die README.md-Datei in das GitHub-Repository hochzuladen.
